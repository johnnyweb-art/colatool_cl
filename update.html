第一次設定 只做一次，1 分鐘

把一顆按鈕放到瀏覽器的書籤列上。之後每個月點它就好，不用碰任何程式碼。

  1. 用電腦的 Chrome 或 Edge 打開這一頁。 手機不行。
  2. 按 Ctrl + Shift + B，讓網址列下方出現書籤列。 Mac 是 ⌘ + Shift + B。書籤列已經有出現就跳過這步。
  3. 用滑鼠按住下面這顆按鈕，拖到書籤列上再放開。
    ▦ 盤點可樂行程

    要用「拖」的，不是點它

  4. 書籤列上出現「盤點可樂行程」，設定就完成了。

每月更新 約 5 分鐘

建議固定在每月第一個上班日做。

  1. 打開可樂旅遊官網 tour.colatour.com.tw
  2. 點書籤列上的「盤點可樂行程」。 右上角會出現深藍色的進度方塊。跑的時候不要關閉、不要切換分頁，大約 3–5 分鐘。
  3. 跑完方塊會顯示「盤點完成」，瀏覽器自動下載 cola-index.js。 通常在電腦的「下載」資料夾。
  4. 上傳到 GitHub，取代舊檔： 打開公司這套工具的 GitHub 頁面 → 按 Add file → Upload files → 把 cola-index.js 拖進去 → 按最下面綠色的 Commit changes
  5. 等 2 分鐘，打開任一個工具頁，捲到結果區最下面，看「行程資料更新日」變成今天。
    日期變成今天，就完成了。不用通知大家，同事下次打開網頁就是新的資料。

出狀況時

大部分狀況都不會弄壞任何東西。照下面處理就好。

下載的檔名變成 cola-index (1).js
是下載資料夾裡已經有舊檔。先把檔名改回 cola-index.js 再上傳，檔名不對，網頁會繼續讀舊的。
檔名是 cola-index_筆數異常_請勿上傳.js
不要上傳。這次抓到的行程比平常少很多，可能是網路不穩或官網改版。隔天再試一次；還是一樣就聯絡顧問。
點書籤跳出「請先打開可樂旅遊官網」
你現在不在官網頁面上。先打開 tour.colatour.com.tw，再點書籤。
跳出「盤點正在進行中」
你點了兩次。等右上角那一次跑完就好。
上傳後過了很久，日期還是舊的
按 Ctrl + F5 強制重新整理。還是舊的，就回 GitHub 確認上傳的檔名是 cola-index.js。
按鈕拖不到書籤列上
用下面的備用方法，效果一樣。
備用方法：不用書籤，直接貼程式碼
  1. 按下面的按鈕複製程式碼
  2. 打開 tour.colatour.com.tw，按 F12，上方選「Console」（主控台）
  3. 第一次貼上時 Chrome 會擋下來並提示，照它說的先輸入 allow pasting 按 Enter
  4. 再貼上程式碼，按 Enter。接下來跟每月更新的第 3 步一樣。

為什麼不能自動更新？可樂官網不允許其他網站直接讀它的資料，所以要在官網頁面上，由瀏覽器自己把行程清單看過一遍再存下來。這支程式做的事，跟你自己一頁一頁點開搜尋結果是一樣的，沒有繞過任何限制，也不會碰到登入或訂單資料。
更新了什麼、沒更新什麼：會更新行程清單、起價與官網顯示的出發日。工具頁上的欄位、規則與畫面不會變。
